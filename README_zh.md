## 为什么使用它？

求职过程中，公司、岗位、截止日期、面试轮次、联系人和跟进事项很容易分散。这个模板把它们集中在一个本地 Excel 工作簿里，无需注册账号、订阅服务或安装插件。

## 主要功能

- 总览页自动统计投递总数、进行中、Offer、已结束/拒绝和 7 天内待办
- 投递追踪页支持筛选并冻结表头
- 阶段、优先级、投递渠道提供下拉选项
- 下一步日期和关键状态带有条件提醒
- 设置页可维护流程阶段、优先级和渠道选项
- 支持离线使用，数据保存在本地

## 快速开始

1. [下载 Excel 模板](templates/%E7%A7%8B%E6%8B%9B%E8%BF%9B%E5%BA%A6%E8%BF%BD%E8%B8%AA%E8%A1%A8.xlsx)。
2. 使用 Microsoft Excel 打开文件。
3. 在「投递追踪」工作表中从第 5 行开始填写公司和岗位。
4. 根据进展更新「当前阶段」「优先级」「下一步日期」等字段。
5. 在「总览」工作表查看自动汇总结果。

## 模板字段

公司、岗位、城市、业务/方向、投递渠道、截止日期、当前阶段、优先级、投递日期、下一步日期、跟进日期、联系人、链接、状态备注和下一步。
